## 问题

论文针对的问题是：LLM 的推理能力（如思维链提示）与行动能力（如动作规划生成）此前基本被当作两个独立课题研究，缺少让二者在同一条轨迹里互相支撑的机制。作者认为交错生成推理与动作能带来协同：推理帮助模型归纳、追踪和更新行动计划并处理异常，行动则让模型能查询知识库或环境以补充信息。这一问题在两处最突出——知识密集型推理中思维链容易凭空编造事实，交互式决策中纯动作策略缺少目标分解与常识引导。

> their abilities for reasoning (e.g. chain-of-thought prompting) and acting (e.g. action plan generation) have primarily been studied as separate topics

> reasoning traces help the model induce, track, and update action plans as well as handle exceptions, while actions allow it to interface with external sources, such as knowledge bases or environments, to gather additional information

## 方法

ReAct 的核心做法是把语言空间并入智能体的动作空间，让冻结的大模型在少样本上下文示例的提示下，交替生成“思考—动作—观测”三元组。作者没有引入额外的格式设计或示例筛选规则：每个上下文示例都是一条人类解题轨迹，思考与动作的出现密度按任务类型调整。对于推理为主的任务，模型被强制密集交替思考与动作；对于动作数量庞大的决策任务，则让模型自行决定异步插入稀疏思考。

**原文依据**

> The idea of ReAct is simple: we augment the agent’s action space

> For the tasks where reasoning is of primary importance (Figure 1(1)), we alternate the generation of thoughts and actions so that the task-solving trajectory consists of multiple thought-action-observation steps.

> so we let the language model decide the asynchronous occurrence of thoughts and actions for itself

> Each in-context example is a human trajectory of actions, thoughts, and environment observations to solve a task instance

## 数据

实验覆盖两类任务。知识密集型推理用 HotpotQA 多跳问答与 FEVER 事实核查，两者都采用只给问题/断言的 question-only 设定，模型必须通过作者自建的简易 Wikipedia API 交互取知识，该 API 只有 search、lookup、finish 三类动作，检索能力明显弱于当时的词法或神经检索器。交互式决策用 ALFWorld（134 个未见评估游戏，需在 50 多个地点中导航并操作物品）和 WebShop（118 万真实商品、1.2 万条人类指令的在线购物环境），后者按平均得分与成功率在 500 条测试指令上评估。

## 局限

作者如实记录了 ReAct 的代价与边界。强制把推理切分到动作步骤之间虽然提高了事实性，却压缩了推理自由度，使 ReAct 在 HotpotQA 上的推理错误率高于 CoT；检索失败也是主要失分来源，占错误案例的 23%，模型一旦拿到无用观测就很难重新组织检索。此外，小模型仅靠提示难以同时学会推理与行动，需要数千条轨迹微调；而动作空间大的复杂任务需要更多示例，很容易超出上下文长度限制，整体效果仍明显落后于人类专家和有监督的专用系统。

**原文依据**

> such a structural constraint also reduces its flexibility in formulating reasoning steps, leading to more reasoning error rate than CoT

> which counts for 23% of the error cases, derails the model reasoning and gives it a hard time to recover and reformulate thoughts

> complex tasks with large action spaces require more demonstrations to learn well, which unfortunately can easily go beyond the input length limit of in-context learning

> existing methods are still far from the performance of expert humans
