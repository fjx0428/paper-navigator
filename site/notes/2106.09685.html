LoRA: Low-Rank Adaptation of Large Language Models

arXiv:2106.09685 · 由论文领航插件自动生成，全部引用经 write_note 逐字校验（仅合并空白）

问题

大规模预训练语言模型要为每个下游任务做全量微调，每个任务都要保存并部署一份与原始模型同样大的参数副本；以 GPT-3 175B 为例，这种部署方式成本高到不可行。已有参数高效方法（adapter、prefix 类）往往引入推理延迟或缩短可用序列长度，且常常达不到全量微调的质量。作者由此假设：模型适配时的权重变化具有很低的“内在秩”，可以把任务增量压缩成小得多的参数集合。

原文依据

Using GPT-3 175B as an example -- deploying independent instances of fine-tuned models, each with 175B parameters, is prohibitively expensive.
As we pre-train larger models, full fine-tuning, which retrains all model parameters, becomes less feasible.
often introduce inference latency (Houlsby et al., 2019; Rebuffi et al., 2017) by extending model depth or reduce the model’s usable sequence length

方法

LoRA 冻结预训练权重 W0，把权重更新重参数化为低秩分解 ΔW=BA（B 为 d×r、A 为 r×k，r 远小于 min(d,k)），前向变成 h=W0x+BAx，只训练 A、B。A 用高斯初始化、B 置零，使训练开始时 ΔW 为零；ΔWx 再按 α/r 缩放，从而在改变 r 时减少超参数重调。推理时把 BA 显式加回 W0，任务切换只需替换低秩矩阵，因此不增加推理延迟；实验主要把 LoRA 施加于注意力的 Wq、Wv，并冻结 MLP。

原文依据

LoRA allows us to train some dense layers in a neural network indirectly by optimizing rank decomposition matrices
In principle, we can apply LoRA to any subset of weight matrices in a neural network to reduce the number of trainable parameters.
We limit our study to only adapting the attention weights for downstream tasks and freeze the MLP modules

数据

实验覆盖 RoBERTa base/large 与 DeBERTa XXL 的 GLUE、GPT-2 medium/large 的 E2E NLG（另含 WebNLG、DART），并扩展到 GPT-3 175B 的 WikiSQL、MultiNLI 与 SAMSum，全部在 NVIDIA Tesla V100 上训练。GPT-3 上 LoRA（4.7M 可训练参数）取得 WikiSQL 73.4、MultiNLI-m 91.7、SAMSum R1/R2/RL 53.8/29.8/45.9，与全量微调的 73.8、89.5、52.0/28.0/44.5 相当或更好。DeBERTa XXL 上 LoRA 仅用 4.7M 参数就把 GLUE 平均分做到 91.3，略高于全量微调的 91.1。

局限

“该把 LoRA 加到哪些权重矩阵”以及秩 r 的选取仍主要依赖启发式规则，小秩并非对所有任务都成立，例如下游任务语言与预训练语言不同时，接近满秩的重训练可能更好。低秩有效性的解释主要是经验性的子空间相似度分析，微调/LoRA 起作用的内在机制仍不清楚。实验只覆盖 Transformer 的注意力权重（MLP 被冻结），并且对特殊 token 过多导致性能下降的现象明确未做深入研究。
