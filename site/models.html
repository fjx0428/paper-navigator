模型怎么选

插件新会话暂定调用智谱 GLM-5.3-Flash（思考等级 high）。已发表的 8 篇评测仍是 DeepSeek-V4.1-Flash，两套数字不要放在一起比。密钥在环境变量 ZHIPU_API_KEY，不进仓库。下面只列这把钥匙实际能调用、并且适合「读论文 + 调工具」的型号。价格是智谱开放平台 2026-11 的按量单价，单位是元 / 百万 tokens。

日常用 GLM-5.3-Flash推荐

输入 0.8、输出 2.8，上下文 100 万。同一把钥匙上已经验证能完成工具调用。一篇论文来回读十几次章节，费用大约是旗舰的十分之一，上下文也盖得住 144 页综述。答辩如果只现场跑一篇、希望工具遵循更稳，再换成 GLM-5.3。

这把钥匙里值得用的四个

模型什么时候用上下文输入 / 输出
glm-5.3-flash反复读论文、复跑、改提示。默认就切这个1M0.8 / 2.8
glm-5.3答辩现场单篇。长程工具调用更稳，不要拿来跑满 8 篇加对照组1M8 / 28
glm-5.3-flashx同一能力想要更低延迟。单价是 Flash 的约 2.5 倍1M2 / 7
glm-4.7上一代通用模型。上下文 20 万，够普通论文，比 5.3 便宜200K短输出约 2 / 8，长输出约 3 / 14

同一把钥匙里先不用的

账号模型列表里还有 glm-5、glm-5.1、glm-5.2、glm-5-turbo、glm-4.6、glm-4.5、glm-4.5-air。它们要么被 5.3 按相近价格盖过，要么上下文更短。glm-5.3-flashx-legal 是法律场景，和读 arXiv 无关。免费的 GLM-4.7-Flash 不在这把钥匙的可用列表里，调用返回的是「访问量过大」，不要写进演示。

图像、语音、视频、向量模型都不进这个插件。论文文本走 PDF 抽取，不把版面交给视觉模型。

和 DeepSeek Flash 怎么分工

DeepSeek-V4.1-FlashGLM-5.3-FlashGLM-5.3
现在的角色评测表、演示脚本、PPT 上的数字接上之后的日常默认单篇冲质量
思考评测时用 High切换脚本设为 high；思考会计入输出额度同左，单次输出上限配到 16384，避免想完没字
不要混着讲换模型之后的笔记不能和现在这张 158/158 的表放在一起比。要新数字，就整表重跑。

切换

改的是 web 和 headless 两个 profile 里「新会话」的默认模型。已经打开的网页要停掉再启动。

node scripts/use-model.mjs                 # 看当前默认
node scripts/use-model.mjs glm-5.3-flash   # 日常
node scripts/use-model.mjs glm-5.3         # 答辩单篇
node scripts/use-model.mjs deepseek-flash  # 回到评测用的模型

智谱这条路由做了三处兼容：系统提示继续用 system 角色（智谱拒绝 developer）、输出上限字段用 max_tokens、思考开关用和 DeepSeek 相同的 thinking.type。模型列表写在 config/zhipu.patch.yml，密钥只出现在本机环境变量和被 git 忽略的 .env。
